# 패밀리플래너 v1.2.0 업데이트

> 출시일: 2026-08-31

## 주요 변경사항

### ✨ 새로운 기능

**루틴(습관 관리)** — 이번 버전의 핵심 신규 기능
- **루틴/습관 관리**: 여러 습관을 하나의 "루틴"으로 묶어 관리합니다. 반복주기(매일/주간/월간), 카테고리 다중 선택, 시간대 지정, 기록방식(체크/횟수/시간)을 지원합니다.
- **일일 목표**: "하루에 N개 달성"을 목표로 설정하고, 습관별로 목표 집계에 포함할지 개별 지정할 수 있습니다.
- **통계**: 전체 루틴 통합 통계 화면에서 주간 습관별 달성 현황, 최근 8주 추이, 기간 이동 조회를 제공합니다.
- **배지 & 랭킹**: 일일 목표 달성률과 연속 달성 기준으로 배지를 획득하고, 그룹 내 랭킹을 겨룰 수 있습니다.
- **그룹 챌린지**: 기간과 목표를 정해 그룹원과 함께 도전합니다. 각자 자신의 습관을 연결해 참가하며 내기를 걸 수도 있습니다.
- **그룹 공유**: 그룹 단위로 습관을 한 번에 공유하고, 숨기고 싶은 습관만 "비공개"로 지정할 수 있습니다.
- **온보딩**: 루틴 목록과 함께하기 화면에 예시 기반 단계별 사용 안내를 제공합니다.

**홈 화면 위젯 (OS 위젯)**
- Android/iOS 홈 화면에 오늘 일정 리스트와 이번달 달력 위젯 2종을 추가했습니다.
- 위젯에서 그룹 필터, 월 이동, 날짜 선택, 일정 추가가 가능하며, 탭하면 앱의 캘린더 화면으로 바로 이동합니다.

**구독 결제**
- 앱 내 구독 결제(In-App Purchase)를 지원합니다. **광고 제거 구독(월 ₩1,900)**을 구매하면 모든 광고가 사라집니다.
- 무료 vs 광고 제거 플랜을 나란히 비교해 혜택을 한눈에 확인할 수 있습니다.
- 구독 복원, 스토어 구독 관리(해지) 화면 진입을 지원합니다.
- 서버 조회가 실패해도 최근 구독 상태를 기억해, 오프라인 상태에서 구독자에게 광고가 잘못 노출되지 않습니다.

### 🐛 버그 수정
- **날씨**: 위치 권한이 거부되거나 조회에 실패했을 때 서울 좌표로 조용히 대체되어 다른 지역 날씨를 보고 있다는 사실을 알 수 없던 문제 수정 (안내 문구와 권한 재요청 버튼 추가)
- **루틴 순서변경**: 순서를 바꿀 때 다른 루틴이 사라지던 문제 수정
- **루틴 통계**: 기간을 이동할 때 화면이 깜빡이고 버튼이 오동작하던 문제 수정
- **루틴**: 날짜 선택 시 경쟁 상태로 잘못된 데이터가 표시되던 문제 수정
- **루틴**: 반복주기를 전환한 뒤 수정 시 오류가 발생하던 문제 수정
- **카테고리**: 편집 목록의 드래그 순서변경이 시트 리사이즈와 충돌하던 문제 수정
- **카테고리**: 카테고리가 0개일 때 추가 버튼이 보이지 않던 문제 수정
- **이모지 피커**: 카테고리 바가 화면을 벗어나던 문제 수정
- **신고 내역**: 내 신고 내역 진입 시 그룹 상세로 잘못 이동하던 라우팅 버그 수정
- **홈 위젯**: Compose Compiler 플러그인 누락으로 위젯이 크래시하던 문제 수정
- **구독**: 구독 화면 진입 시 가격이 바로 안 뜨고 아무 버튼이나 눌러야 나타나던 문제 수정
- **구독**: 이미 구독 중인데도 구매 버튼이 계속 눌리던 문제 수정
- **구독**: 과거 구매 내역이 재전달될 때마다 "구독 완료" 알림이 반복적으로 뜨던 문제 수정
- **구독**: 구매 직후 앱이 종료되는 등의 이유로 서버 반영이 누락될 수 있던 문제 수정 (앱 재실행 시 자동 재시도)
- **전역**: API 요청이 짧은 시간에 여러 번 실패하면 알림 배너가 큐에 쌓여 계속 순서대로 표시되던 문제 수정

### 🔧 개선사항
- **저장 버튼 통일**: 생성/수정 화면의 저장 버튼을 하단 고정 방식으로 통일하고, 화면 좌우/하단 세이프존을 확보했습니다.
- **이모지 선택**: 자체 이모지 피커로 전환해 한국어 검색을 지원하고, 그리드를 레이지 렌더링으로 바꿔 성능을 개선했습니다.
- **색상 선택**: 루틴 색상 선택 방식을 프로필 설정과 동일하게 통일했습니다.
- **루틴 목록**: 그리드 레이아웃으로 전환하고, 순서변경을 앱바 편집 모드에서 드래그로 처리하도록 개선했습니다.
- **독립 습관 배치**: 루틴 그룹 사이 원하는 위치에 자유롭게 배치할 수 있습니다.
- **알림 설정**: 알림 설정 화면에 세이프존을 적용했습니다.
- **디자인 일관성**: SegmentedButton 선택 체크 아이콘을 전 프로젝트에서 숨겨 표기를 통일했습니다.
- **구독 진입로**: 설정 화면 구독 카드, 대시보드 체험 배너에서도 구독 화면으로 바로 이동할 수 있습니다.

## 앱스토어 업데이트 내용

> 아래 내용을 앱스토어(App Store Connect / Google Play Console) 업데이트 설명란에 붙여넣으세요.

```
[v1.2.0] 습관 관리·구독 결제 출시 및 홈 화면 위젯 추가

이번 업데이트에서는 다음 내용이 개선되었습니다.

■ 새로운 기능
• 습관 관리 기능이 추가되었습니다. 여러 습관을 루틴으로 묶고, 하루 목표를 정해 관리할 수 있습니다.
• 가족·친구 그룹과 습관을 공유하고 랭킹과 챌린지로 함께 도전할 수 있습니다.
• 달성 기록에 따라 배지를 획득하고, 주간·월간 통계로 진행 상황을 확인할 수 있습니다.
• 홈 화면 위젯이 추가되었습니다. 오늘 일정과 이번달 달력을 앱을 열지 않고 바로 확인하세요.
• 광고 제거 구독(월 1,900원)을 도입했습니다. 더보기 탭에서 구독할 수 있습니다.

■ 버그 수정
• 위치 조회에 실패했을 때 다른 지역 날씨가 표시되던 문제를 수정했습니다.
• 목록 순서를 변경할 때 항목이 사라지던 문제를 수정했습니다.
• 통계 화면에서 기간을 이동할 때 화면이 깜빡이던 문제를 수정했습니다.

■ 개선사항
• 저장 버튼을 화면 하단에 고정해 어느 화면에서나 편하게 저장할 수 있습니다.
• 이모지 검색에 한국어를 지원하고 선택 속도를 개선했습니다.
```
